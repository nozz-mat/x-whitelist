# X Whitelist Only

X（Twitter）の投稿を、許可したアカウントだけ表示するためのChrome拡張機能です。

許可リストに登録されていない投稿やアカウントへのリンクは、Xの画面上から非表示または無効化されます。

## 主な機能

- 許可リストへのアカウント登録・削除
- 許可リストにない投稿の非表示
- 引用投稿の投稿元アカウントを個別に判定
- 未許可アカウントへのプロフィールリンクを無効化
- 「おすすめ」タブを非表示化し、可能な場合は「フォロー中」へ切り替え
- サイドバー、検索、投稿作成、リアクション、投稿メニューなど一部UIの非表示化
- フォロー中一覧から許可アカウントを一括登録
- 許可リストのリアルタイム反映
- フォロー・フォロー解除操作時に許可リストへ反映

## 動作要件

- Chromium系ブラウザ（Google Chromeなど）
- Manifest V3対応ブラウザ
- `https://x.com/*` または `https://www.x.com/*` へのアクセス

## インストール方法

1. このリポジトリを任意の場所に保存します。
2. Chromeで `chrome://extensions/` を開きます。
3. 右上の「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」を選択します。
5. このREADMEがあるフォルダ（`manifest.json` があるフォルダ）を選択します。

インストール後、Xを開いて拡張機能が有効になっていることを確認してください。  
コードを変更した場合は、拡張機能管理画面で更新ボタンを押してください。

## 使用方法

### 1. ポップアップを開く

ブラウザのツールバーにある「X Whitelist」をクリックします。

### 2. アカウントを登録する

1. 入力欄にユーザー名を入力します。
2. `@` はあってもなくても構いません。
3. 「追加」を押します。

例:

```text
@example_user
```

ユーザー名は英数字とアンダースコアのみ、最大15文字まで登録できます。登録済みのユーザー名は重複して追加されません。

登録後にプロフィールを開く確認が表示されます。必要に応じて「プロフィールを開いてフォローする」を選ぶと、そのアカウントのプロフィールが新しいタブで開きます。フォロー操作自体はX上で利用者が行います。

### 3. フォロー中のアカウントを一括登録する

1. ポップアップで「フォロー中を一括登録」を押します。
2. 現在開いているタブがXのページである必要があります。
3. 新しいタブでフォロー中一覧が読み込まれ、画面上部に進行状況が表示されます。
4. 読み込み完了後、確認済みのアカウントが許可リストへ追加されます。

フォロー中一覧は自動スクロールされます。大量のフォロー中アカウントがある場合は、読み込みに時間がかかることがあります。

### 4. アカウントを削除する

ポップアップの許可アカウント一覧で、対象アカウントの右側にある「削除」を押します。

## 保存されるデータ

許可リストはChromeのローカルストレージに保存されます。

- キー: `xwl_allowed_users`
- 保存形式: ユーザー名文字列の配列
- 保存先: `chrome.storage.local`

サーバーへの送信や外部サービスへのデータ送信は行いません。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `manifest.json` | 拡張機能の定義、権限、コンテンツスクリプト |
| `popup.html` | 設定ポップアップの構造 |
| `popup.css` | 設定ポップアップのスタイル |
| `popup.js` | 許可リストの登録・削除・一括インポート操作 |
| `content.js` | X画面の投稿・リンク・UIフィルタリング処理 |
| `filter.css` | X画面に適用する非表示スタイル |

## 制限事項

- XのHTML構造や `data-testid` が変更されると、フィルタリングや一括インポートが正常に動作しない場合があります。
- 投稿者を判定できない投稿は、誤検出防止のため非表示になります。
- フォロー中一覧の自動読み込みには、X側のレンダリング完了を待つ処理が含まれます。
- 拡張機能はXのフォロー操作を代行しません。
- ブラウザ側で拡張機能を無効化すると、フィルタリングも停止します。

## 開発時の確認

XのページでDeveloper Toolsを開き、コンソールの次のプレフィックスを確認できます。

```text
[XWL]
```

設定変更後は、ポップアップで保存された許可リストがXのタブへ即時反映されます。
